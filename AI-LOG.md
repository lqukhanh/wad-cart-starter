**Asked for:**
Implement the `cartTotal` function in `src/cart.js` and unit tests in `test/cart.test.js` based on `brief.md` without external dependencies.

**What it produced:**

**What I changed:**
- **Defensive handling for options:** Updated function signature to `options = {}` and used `options || {}` before destructuring to avoid runtime crashes (`TypeError`) when `options` is missing or passed as `null`.
- **Hardened item validation:** Added `typeof item.price !== 'number'` and `Number.isNaN(item.price)` checks inside the loop to prevent `undefined` or `NaN` from silently propagating into `subtotal`.
- **Added options range validation:** Enforced `RangeError` checks for negative values or incorrect types on `vatRate`, `shipFee`, and `freeShipFrom`.
- **Added input type validation:** Added `!Array.isArray(items)` throwing `TypeError` at the top of the function.

**What I rejected:**
- **Unsafe destructuring:** Rejected the direct `const { vatRate, freeShipFrom, shipFee } = options` pattern generated by the AI because it assumed `options` is always a valid object.
- **Permissive price condition:** Rejected the AI's simple `item.price < 0` check because JavaScript treats `NaN < 0` as `false`, which would allow missing or malformed price fields to pass through unnoticed.
